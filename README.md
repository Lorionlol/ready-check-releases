# Ready Check

**FR** — Un roguelike à la Balatro sur la vie d'un raid leader de MMO. Ce dépôt ne contient que l'installeur du jeu et ses mises à jour, pas le code source.

**Installer :** ouvre l'onglet [Releases](https://github.com/Lorionlol/ready-check-releases/releases), télécharge `Ready Check Setup x.y.z.exe` et lance-le. Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur » : clique sur « Informations complémentaires » puis « Exécuter quand même » (le jeu n'est pas encore signé). Ensuite, le launcher installe tout seul les nouvelles versions.

**Sécurité :** chaque version est analysée par [VirusTotal](https://www.virustotal.com) (environ 65 antivirus). Le lien du rapport public et l'empreinte SHA-256 du fichier sont dans les notes de chaque release, section « VirusTotal ». Dernière analyse (3.10.8) : **0/62** — [voir le rapport](https://www.virustotal.com/gui/file/b7a90cff4d94b68b922915b89dcb6042d2660bfc0039857dd5b8cbd5dc90bc68).

**EN** — A Balatro-like roguelike about the life of an MMO raid leader. This repository only holds the game installer and its updates, not the source code.

**Install:** open [Releases](https://github.com/Lorionlol/ready-check-releases/releases), download `Ready Check Setup x.y.z.exe` and run it. On first launch Windows may show "Windows protected your PC": click "More info", then "Run anyway" (the game is not signed yet). After that, the launcher installs new versions by itself.

**Safety:** every version is scanned by [VirusTotal](https://www.virustotal.com) (about 65 antivirus engines). The public report link and the file's SHA-256 are in each release's notes, « VirusTotal » section. Latest scan (3.10.8): **0/62** — [see the report](https://www.virustotal.com/gui/file/b7a90cff4d94b68b922915b89dcb6042d2660bfc0039857dd5b8cbd5dc90bc68).
